# NO MOUSE!
A simple puzzle game where you only have access to your keyboard.

<img width="600" height="150" alt="image" src="https://github.com/user-attachments/assets/4d81441b-cbd4-49c9-b7c7-0df10e742756" />

You can play **NO MOUSE!!** at: https://marygoat.itch.io/no-mouse. To start, just press run.

## Controls

- Your keyboard!

## Features

4 simple puzzles, such as:

- Bring the box to the end!
- Spelling bee!
- X marks the spot!
- Find the word!

Made in Godot for the Tabbed Hack Club program.

I made this game in a short amount of time without the intent of making it a really polished game, but maybe if I get some ideas I'll come back and polish it a bit more!

## AI Usage

I used Claude to help me debug small bugs.
